This is the special `.github` repository for the [UCSD-SIO-CDIP](https://github.com/UCSD-SIO-CDIP) organization. GitHub uses repositories named `.github` to store organization-wide defaults and community health files that apply automatically across every repository in the organization, unless a repository provides its own override.

This repository is **public** and its contents are visible to the world at-large. For **private** configuration and internal docs, see [`.github-private`](https://github.com/UCSD-SIO-CDIP/.github-private).

## What This Repository Provides

### `profile/README.md`

The public-facing profile page displayed on the [organization's GitHub page](https://github.com/UCSD-SIO-CDIP). This is typically the first thing visitors see when they land on the org, so it should introduce CDIP and highlight relevant projects and resources.

### `CONTRIBUTORS.md`

A default contributing guide. Because it lives in the `.github` repository, GitHub automatically surfaces it as the "Contributing" guidelines for any repository in the organization that does not define its own `CONTRIBUTING.md`. This provides a consistent, org-wide contribution workflow (branching strategy, pull request expectations, review process, etc.) without needing to duplicate the file in every repo.

## Adding or Updating Org-Wide Defaults

Changes made here affect the entire organization, so please:

- Review changes carefully before merging, since they apply broadly.
- Keep guidance general enough to make sense across different repositories/projects.
- Prefer repository-specific overrides (e.g., a repo's own `CONTRIBUTING.md`) when a project has needs that differ significantly from the org default.
